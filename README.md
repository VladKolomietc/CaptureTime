# CaptureTime Bot 🕒

Естетичний Telegram-бот для трекінгу часу. Головною особливістю проєкту є чітка дискретність по днях та прив'язка кожного сеансу фокусу до музичної композиції, що допомагає зафіксувати не лише продуктивність, а й настрій.

**Основні можливості**
* **Гнучке завантаження:** Дані можна додавати текстом (за заданим шаблоном) або просто надіславши скріншот екрана блокування iOS.
* **Розумний парсинг дат:** Бот автоматично визначає дату зі скріншоту. Пріоритети розпізнавання:
  1. Назва файлу (якщо фото відправлено як документ без стиснення).
  2. Текстовий підпис під фотографією.
  3. OCR-дані безпосередньо з самого зображення.
* **Керування записами:** Вбудоване меню для зручного редагування та видалення збережених даних, якщо щось пішло не так.
* **Базова аналітика:** Генерація примітивного списку записів та побудова графіка активності (день — час).

> **⚠️ Примітка:** Наразі ліміти на завантаження та розпізнавання фотографій дуже обмежені, тому функція може працювати з перебоями. Текстове введення залишається найстабільнішим методом.

**Доступні команди**
* `/start` — Створити запис користувача в базі даних та запустити бота.
* `/exit` — Глобальний вихід у головне меню з будь-якого стану.

**Технологічний стек**
Проєкт побудований на сучасному асинхронному стеку Python:
* **Бекенд:** `aiogram 3.30` (асинхронний фреймворк для Telegram)
* **База даних:** SQLite (через `aiosqlite`)
* **Розпізнавання тексту (OCR):** `google-genai` (Gemini API)
* **Графіки та аналітика:** `matplotlib`, `seaborn`, `pandas`
